🚀 Companion Server Quick Setup

Get up and running in 3 simple steps

⚠️ Companion Server Required
The companion server enables IDE integration (Claude Code, VS Code) and fix workflows. It runs locally on your machine and handles editor launches.
1 Check Prerequisites

You need Node.js v16+ installed. Check if you have it:

node --version
Don't have Node.js? Install it:
  • Ubuntu/Debian: sudo apt install nodejs npm
  • macOS: brew install node
  • Windows: Download from nodejs.org
2 Install Companion CLI

Navigate to your project directory and run the install check:

cd dependency-mapper-python ./companion-cli.sh install
Expected output: 
✓ Node.js v20.x.x installed
✓ Companion files found
✓ Installation check complete!
3 Start the Companion

Start the companion server (runs in background):

./companion-cli.sh start

Verify it's running:

./companion-cli.sh test
Expected output: 
✓ Companion is running
✓ Health check passed
Response: {"status":"ok"}

🔧 Troubleshooting

Port 3000 already in use?

./companion-cli.sh start 19280

Check if running:

./companion-cli.sh status

View logs:

./companion-cli.sh logs

Restart:

./companion-cli.sh restart
